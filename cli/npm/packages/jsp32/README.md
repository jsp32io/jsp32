# jsp32

Public-name entry point for [`@jsp32/jsp32`](https://www.npmjs.com/package/@jsp32/jsp32).
Requires Node.js 18 or later.

```sh
npm install -g jsp32
jsp32 --help
# Or without a global install:
npx jsp32 --help
```

Supports Windows amd64/arm64, Linux amd64/arm64 and macOS arm64.
The matching native CLI is installed through optional dependencies.
